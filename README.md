## ✨ Features & Architecture

- **Day / Night Mode (White Shade vs. Emerald Dark Shade):**
  - Seamless one-click toggle between luxury emerald dark mode and a luminous, multi-tonal emerald/mint shaded light mode.
  - State persisted across sessions using `localStorage`.
- **Interactive Color Moods:**
  - Real-time accent switching: *Emerald Silicon*, *Cyber Violet*, *Obsidian Gold*, and *Cosmic Azure*.
- **Scroll Fade-In & Fade-Out Transitions:**
  - Dynamic viewport-triggered animations on the single vertical stream of project cards.
- **Interactive Ambient Particle Canvas:**
  - Responsive HTML5 Canvas with glowing particle mesh that reacts to cursor proximity.
- **Enterprise Consultation Hub:**
  - Interactive consultation form pre-formatting and directing corporate inquiries.

## 🛠️ Local Development

Clone the repository and launch a local web server:

```bash
# Clone repository
git clone https://github.com/ProdiptoPantho/think-silicon.git

# Navigate to project folder
cd think-silicon

# Run local static server (Python or Node)
python -m http.server 3000
# or
npx serve .
```

Open `http://localhost:3000` in any modern web browser.
